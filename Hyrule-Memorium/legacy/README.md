# Legado do web-data-viz

Esta pasta guarda cópias dos arquivos originais do projeto `web-data-viz`.

## Por que ela existe

O Hyrule-Memorium foi criado a partir do web-data-viz. Várias páginas e recursos
foram alterados para contar a história e as memórias dos jogos de Zelda.

Estes arquivos são apenas referência de estudo. Eles não são usados pelo site
atual e não devem ser ativados sem revisar rotas, banco e controllers.

## O que mudou

- AquaTech virou Hyrule Memorium.
- O usuário continua no projeto, mas já não precisa pertencer a uma empresa.
- Avisos viraram memórias no Mural.
- O gráfico de temperatura virou gráfico de jogos mais marcantes.
- `questionario` é a tabela criada no Hyrule-Memorium para guardar as memórias exibidas no Mural.
